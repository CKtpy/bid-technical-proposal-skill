# 投标技术标撰写与核查

## 定位与边界

本 Skill 只处理**技术标**：技术方案正文、技术偏离表、评分点/废标项拆解、招标符合性核查。

- **不代拟商务标**：报价一览表、单价/总价/优惠率、资格资质、业绩、专利、体系证书、人员简历、保函等，只标注"商务项，待商务标补充"并提醒别漏装，不虚构、不代写。
- **技术方案正文内禁止出现报价**（单价、总价、折扣、优惠率一律不进正文）。
- 遇到招标文件本身口径矛盾、参数反常或证据不足时，独立指出问题与风险，不迎合、不编造。

## 工作流总览

按顺序执行，详细分步规则见 [references/workflow.md](references/workflow.md)：

1. **冻结版本并通读提取**：项目名称/编号、采购内容与数量、技术条款、评分表、商务边界（交货期/质保/售后）、废标条款、装订格式要求。
2. **逐条拆解分级**：提取评分点与废标项，区分 ★ / ▲ / 一般条款，形成评分点-风险对照表（模板见 assets）。分级口径以招标文件原文说明为准，不要套用固定印象。
3. **生成技术标目录**：把每条条款映射到正文章节，标注风险等级、所需支撑材料、待澄清项。
4. **撰写技术方案正文**：套用 [assets/technical-proposal-outline.md](assets/technical-proposal-outline.md)；逐条款响应，参数、数量、单位、标准号与招标一致。
5. **编制技术偏离表**：套用 [assets/deviation-table-template.md](assets/deviation-table-template.md)；招标原文栏含规格、计量单位、采购数量；响应栏改写表述；逐条标偏离度。
6. **互核与终审**：偏离表 ↔ 正文逐项对应；图/表/正文数字勾稽；标准号核对；输出问题清单与待补材料清单；保留多版本轨迹。

## 硬性红线（速览）

完整雷区与处理规则见 [references/redlines.md](references/redlines.md)，动手前必读：

- 不伪造资质、报告编号、检测报告、业绩、专利、证书、制造商证明；无凭据一律标"待补/待核"。
- ★ 多为实质性/废标项，不响应或负偏离风险最高；▲ 为重要条款；一般条款次之。具体后果以招标文件约定为准。
- 偏离表不得整段照抄招标原文；响应要具体化，不能空口承诺，★/▲ 条款需列出支撑材料。
- 招标明显笔误（尺寸/数量/单位反常）：偏离表照抄原文、标无偏离并注明"原文如此，待书面澄清"；正文若改实际口径，必须避免与偏离表矛盾，并把决策点交给用户。
- 技术条款、标准号（GJB/GB/行业标准）与招标原文逐字核对，不确定的标待核。

## 审核准则（五准则）

每轮交付前按 [references/review-checklist.md](references/review-checklist.md) 自查，核心五条：

1. 检查错误前提、逻辑漏洞与信息缺失。
2. 独立判断，不迎合；发现口径问题直接指出。
3. 核验数字、计量单位、数量、型号、标准号、结论。
4. 发现错误直接说明依据与风险。
5. 主动提醒遗漏变量、成本、偏差。

## 领域背景

常见装备品类、配套技术（HMI/PLC/嵌入式/数据滤波）、技术方案常见章节要素，见 [references/domain-notes.md](references/domain-notes.md)。涉及具体算法、受力分析、参数计算时，给出思路、公式与测试步骤，不写黑盒结论。
