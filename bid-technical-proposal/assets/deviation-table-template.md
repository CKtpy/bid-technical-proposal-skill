## 填写规则

1. **级别列**：按招标原文符号标注 ★ / ▲ / 一般；符号规则以招标文件说明为准。
2. **招标技术要求栏**：
   - 保留原文措辞、数值、单位、数量；整组要求拆到子项逐项成行。
   - 原文明显笔误时照抄原文，在备注列写"招标原文如此，待书面澄清"。
3. **投标响应栏**：
   - 用自己的话组织，避免整段雷同；先结论后具体参数。
   - 标准句式参考："完全响应招标要求；我方采用【配置/方案】，参数为【实测/设计值】，【优于/满足】招标【具体指标】。"
   - 无方案依据的参数不写死，标"待核"。
4. **偏离情况列**：
   - 无偏离：响应满足招标要求；正偏离：指标优于要求并写明优于项；负偏离：不满足项，必须显式标出并提示风险。
   - 不得把负偏离填入"无偏离"。
5. **支撑材料列**：检测报告、规格书、制造商证明、截图、图纸等对应编号或正文页码；暂未取得标"待补"。
6. **计数核对**：表内行数应与招标条目数一致；交付前逐项点数，防止漏行。
