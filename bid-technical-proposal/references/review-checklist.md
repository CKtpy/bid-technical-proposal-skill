## 五条审核准则

每轮自检和复核都遵循以下五条，顺序不可省：

1. **查错误前提、逻辑漏洞与信息缺失**：方案是否建立在错误假设上；前后论述是否自洽；有没有漏掉招标明确要求的内容。
2. **独立判断，不迎合**：用户口径或招标文件口径有问题时，直接指出；不为了顺从而附和错误结论。
3. **核验数字与流程**：数量、单位、型号、参数、标准号、日期、人物、结论逐项核对来源；数字勾稽一致。
4. **发现错误直接指出**：说明错误是什么、依据在哪、风险是什么，不只给"建议修改"。
5. **主动提醒遗漏变量**：成本、周期、供货来源、支撑材料、偏差后果等未覆盖项，主动提示用户决策。

## 终审逐项核查清单

交付前逐条勾选；任一"否"都要列入问题清单：

### 条款覆盖

- [ ] 招标文件全部技术条款均已响应，无整项遗漏。
- [ ] ★ 条款逐条正面响应，支撑材料已列明或标待补。
- [ ] ▲ 条款逐条正面响应，无敷衍表述。
- [ ] 采购数量、计量单位、规格参数在偏离表中完整体现。
- [ ] 补遗/答疑新增条款已回填对照表与偏离表。

### 一致性

- [ ] 偏离表每条承诺在正文中有对应章节与论述。
- [ ] 正文写到的实质指标在偏离表中有对应行。
- [ ] 台套数、数量、单位、参数、交货期、质保月数、售后响应时限在图、表、正文三处一致。
- [ ] 标准号与招标原文一致，版本/年代号正确。

### 合规与红线

- [ ] 正文无报价、单价、总价、折扣、优惠率。
- [ ] 无虚构资质、证书编号、报告编号、业绩、专利、人员信息。
- [ ] 负偏离已显式标注，未混入"无偏离"。
- [ ] 招标笔误/矛盾参数已备注并提示书面澄清。
- [ ] 待澄清、待补材料已单列，未夹带虚构凭据。

### 完整性提醒

- [ ] 商务评分附件（业绩、专利、证书、资质）已提醒用户在商务标核对，未在技术标虚构。
- [ ] 图号、表号、目录页码齐全；预留示意图位置。
- [ ] 文件版本命名清晰，上一版已保留。

## 问题分级与交付口径

- **高风险**：废标项未响应、★/▲ 条款空口承诺、参数矛盾、漏项、虚构凭据——必须在交付首段列出。
- **中风险**：支撑材料待补、表述含糊、非关键参数待澄清。
- **低风险**：排版、图注、措辞优化。

交付说明包含：本轮完成内容、遗留待用户拍板的口径、待补材料清单、下一版建议动作。不声称文件已提交、已盖章、已取得报告或已通过评审。
